# \# StaffSync

# 

# \## Modern Human Resource Management System

# 

# StaffSync is a web-based HR management system developed using the MERN stack as a capstone project for the SkillWallet Full Stack Development course.

# 

# \### Live Links

# \- \*\*Live Demo:\*\* https://staff-sync-steel.vercel.app/

# \- \*\*GitHub Repository:\*\* https://github.com/sanidhyas698-collab/StaffSync

# \- \*\*Backend API:\*\* https://staffsync-api-qa7i.onrender.com

# 

# \### Features

# \- HR dashboard

# \- Employee management

# \- Employee listing

# \- Leave request management

# \- Approve or reject leave requests

# \- Frontend and backend API integration

# 

# \### Technologies Used

# \- React.js

# \- Vite

# \- Node.js

# \- Express.js

# \- JavaScript

# \- REST API

# 

# \### Project Status

# The application is deployed online. Employee and leave data are currently stored in backend memory and may reset when the backend restarts.
